01 // SPECIFICATION

What is EBNF?

Extended Backus–Naur Form is a formal metasyntax used to define the production rules and allowable syntax of a programming language without ambiguity.

02 // SYNTAX ANALYSIS

Concrete Parse Tree

A hierarchical tree that represents the complete, concrete syntactic structure of your source string—including every terminal symbol, delimiter, and parenthesis.

03 // SEMANTIC STRUCTURE

Abstract Syntax Tree (AST)

A condensed syntax tree that discards redundant grammar details (like punctuation and grouping symbols) to focus strictly on structural operations and variables.

Generated EBNF Grammar

Grammar 
Program = { Statement } ;
Statement = Assignment | IfStmt | WhileStmt | ReturnStmt | ExprStmt ;
Assignment = Identifier, "=", Expression, NEWLINE ;
IfStmt = "if", Expression, ":", Suite,
         { "elif", Expression, ":", Suite },
         [ "else", ":", Suite ] ;
WhileStmt = "while", Expression, ":", Suite ;
ReturnStmt = "return", [ Expression ], NEWLINE ;
ExprStmt = Expression, NEWLINE ;
Suite = NEWLINE, INDENT, { Statement }, DEDENT ;
Expression = OrExpr ;
OrExpr = AndExpr, { "or", AndExpr } ;
AndExpr = CompareExpr, { "and", CompareExpr } ;
CompareExpr = AddExpr, [ CompOp, AddExpr ] ;
AddExpr = MulExpr, { ("+" | "-"), MulExpr } ;
MulExpr = UnaryExpr, { ("*" | "/" | "%" | "//"), UnaryExpr } ;
UnaryExpr = [ ("+" | "-") ], Primary ;
Primary = NUMBER | STRING | "True" | "False" | "None" | Identifier | "(", Expression, ")" ;
